> 各章の「▼ 追加項目」欄に、いただいた項目を追記していきます。

---

## 全体の流れ（ストーリーライン）

```
0. オープニング   … なぜ今テキーラなのか（つかみ）
1. 基礎知識        … テキーラとは何か（定義・原料・製法・分類）
2. 味わい方        … 基礎を舌で確かめる（テイスティング）
3. アメリカの最新トレンド … 世界最大市場で何が起きているか
4. 日本の最新トレンド     … 日本市場の現在地と伸びしろ
5. 日米比較と今後の展望   … 2つの市場から見える未来
6. クロージング    … まとめ・Q&A・次のアクション
```

**流れの考え方**
- 「知る（基礎）→ 味わう（体験）→ 世界を見る（米国）→ 足元を見る（日本）→ 未来を考える（比較・展望）」の順。
- 基礎知識を先に入れておくことで、トレンド章の用語（100%アガベ、アディティブフリー、エクストラアネホ等）がスムーズに伝わる。
- アメリカ → 日本の順にすることで「米国で起きたことが日本にどう波及するか」という比較の軸が自然に作れる。

## 1. テキーラの基礎知識（約20分）
### 1-1. テキーラとは
- 定義（原産地呼称 / NOM / CRT）
- テキーラとメスカルの違い

### 1-2. 原料：ブルーアガベ
- アガベ・テキラーナ・ウェーバー・アスル
- 栽培期間と産地（ハイランド / ローランド）

### 1-3. 製法
- 収穫（ヒマドール）→ 加熱（窯・オートクレーブ・ディフューザー）→ 搾汁 → 発酵 → 蒸留 → 熟成

### 1-4. 分類
- 原料比率：100%アガベ / ミクスト
- 熟成区分：ブランコ / ホーベン / レポサド / アネホ / エクストラアネホ（＋クリスタリーノ）
