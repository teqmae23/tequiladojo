## 全体の流れ

```
第1部 テキーラの基礎知識
  1-1 テキーラとは（定義）
  1-2 原材料：アガベ・アスル
  1-3 生産地（ハリスコ州全域＋4州の一部地域）
  1-4 カテゴリー（100%アガベ / ミクスト）
  1-5 クラス（ブランコ / レポサド / アネホ / エクストラアネホ）
  1-6 製造工程
  ★ 結論：テキーラブランコがすべてのテキーラの原点

第2部 日米の最新トレンド
  2-1 輸出量の推移（1980年頃〜2025年）
  2-2 輸出の傾向（国内消費と輸出の内訳、輸出先の偏り）
  2-3 メキシコは「アメリカ向け」を意識してテキーラを造っている
  2-4 コロナ禍が世界と日本への輸出に与えた影響
  2-5 アメリカ（海外）の最新トレンド
  2-6 日本の最新トレンド
```

**話の筋**
- 第1部は「何か（定義）→ 何から（アガベ）→ どこで（産地）→ どう分けるか（カテゴリー・クラス）→ どう造るか（製造工程）」の順です。最後に「ブランコが原点」という結論を置いて締めます。
- 第2部は「数字で全体像を見る（輸出推移・輸出先）→ だからメキシコはアメリカを見ている → コロナ禍で何が起きたか → 今、何が飲まれているか（米→日）」の順です。

## 第1部 テキーラの基礎知識

### 1-1. テキーラとは（定義）
- テキーラの定義（原産地呼称、NOM 規格、CRT〈テキーラ規制委員会〉）

### 1-2. 原材料：アガベ・アスル
- アガベ・テキラーナ・ウェーバー・アスル種とは
- 栽培期間など、原料としての特徴

### 1-3. 生産地
- ハリスコ州全域と、他4州の一部地域（グアナファト、ミチョアカン、ナヤリット、タマウリパス）
- 【資料】原産地呼称の範囲を示す地図

### 1-4. カテゴリー（原料による分類）
- 100%アガベテキーラ
- ミクストテキーラ

### 1-5. クラス（熟成による分類）
- ブランコ
- レポサド
- アネホ
- エクストラアネホ

### 1-6. 製造工程
- 一連の流れで説明：収穫 → 加熱 → 搾汁 → 発酵 → 蒸留 → 熟成

### ★ 第1部の結論
- **テキーラブランコがすべてのテキーラの原点**

## 第2部 日米の最新トレンド

### 2-1. 輸出量の推移（1980年頃〜2025年）
- 【資料】輸出量の推移グラフ
- ポイント：**右肩上がりで成長を続けている**

### 2-2. 輸出の傾向
- 全生産量のうち、メキシコ国内の消費と輸出の内訳（約半分が輸出）
- 輸出先の内訳（輸出量の約80%がアメリカ向け）
- 【資料】国内消費と輸出の比率、輸出先の国別シェア

### 2-3. メキシコは「アメリカ向け」を意識している
- 輸出がアメリカ中心に動いている
- そのため、メキシコのメーカーは常にアメリカ市場を意識した商品づくりをしている

### 2-4. コロナ禍が世界と日本への輸出に与えた影響
- 【資料】コロナ前後の、世界全体と日本向けの輸出量の推移

### 2-5. アメリカ（海外）の最新トレンド
- いま、どんなテキーラが飲まれているか
