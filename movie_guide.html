この動画は 360°映像です。画面の中で見たい方向を自由に動かして楽しめます。ご利用の端末によって操作が少し異なります。

📱 iPhone / iPadスワイプ傾け操作なし

Safari など（iOS）
  • 画面を指でスワイプすると、見たい方向へ視点が動きます。
  • プレイヤーの全画面ボタン（⛶）で大きく表示できます。
  • iPhone / iPad は、端末を傾けて見る「ジャイロ操作」には対応していません。スワイプでご覧ください。

🤖 Androidスワイプ傾け操作OK

Chrome など（Android）
  • 画面を指でスワイプして見回せます。
  • 対応端末では、スマホ本体を持って向きを変える（ジャイロ）と、その方向の映像が見えます。端末を上下・左右に向けてお試しください。
  • 傾けても動かない場合は、スワイプでご覧ください（機種によりジャイロ非搭載のことがあります）。

💻 パソコンドラッグ

Chrome / Safari / Edge など（ブラウザ）
  • 映像をマウスでドラッグすると視点が動きます。
  • 全画面ボタンで大きく表示できます。

❓ うまく見えないとき

視点が動かない
まず再生ボタンで再生してから、スワイプ／ドラッグしてください。
映像が止まる・粗い
通信環境の良い場所でご視聴ください。画質は自動調整されます。
音が出ない
プレイヤーのミュート解除と端末の音量をご確認ください。
最新のブラウザで
Safari / Chrome を最新版にすると安定します。
